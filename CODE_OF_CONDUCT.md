# Code of Conduct

CinemaTrack is a friendly project. We want it to be easy and pleasant for anyone to take part,
whatever their background or experience.

**Do**
- Be kind and patient, especially with people who are new to open source or to the tools used here.
- Give feedback on the work, not the person, and explain your reasoning.
- Assume good intentions; ask when something is unclear.
- Credit other people's work and ideas.

**Do not**
- Harass, insult or demean anyone, or make personal attacks.
- Share other people's private information.
- Use the project's spaces (issues, pull requests, discussions) for spam or for anything unrelated to the project.

**Reporting.** If someone behaves badly, tell the maintainers privately via GitHub (Security tab → "Report a vulnerability" works for
conduct reports too, or contact the repository owner through their GitHub profile). Reports are handled confidentially.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may ask a person to leave the
project's spaces if needed. This applies to all project spaces and to anyone representing the project in public.
