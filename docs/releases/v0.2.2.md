# CinemaTrack 0.2.2

The fourth test release. It follows up on the display-name filter from 0.2.1, which testers found too easy to get around,
and lets names use Turkish letters.

## Download

- **Windows:** `CinemaTrack-Setup-0.2.2.exe`
- **Android:** `CinemaTrack-0.2.2.apk`

Both are not code-signed yet, so Windows shows a "protected your PC" warning (More info → Run anyway) and Android asks you to allow
installing from this source. Step-by-step help is in the [tester guide](../tester-guide.md). `SHA256SUMS.txt` lets you check the files.

**Updating:** install over the old version; your account and lists stay.

## What's new

- **Turkish letters in display names.** "Çağlar", "Şebnem" or "Ömer" were refused before; now ç ğ ı ö ş ü İ and other accented
  Latin letters are fine. Other alphabets (Cyrillic, Arabic, …) are still not accepted, because the name filter can only read Latin letters.
- **A much wider name filter.** Many profane names slipped through, mostly Turkish forms and abbreviations, some insults and more English terms.
  The list lives on the server, so it already applies to older versions of the apps.
- **The installer file name has no spaces** (`CinemaTrack-Setup-0.2.2.exe`), so it is the same on GitHub as in the checksum file.

## Good to know

- You need an account with a **real email address**. Your lists and notes are private to you.
- The AI features have daily limits (for example 30 chat messages and 10 Watch Together picks per person).
- The name check needs the internet; if it cannot be reached, your name is accepted as it is.
