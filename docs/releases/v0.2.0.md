# CinemaTrack 0.2.0

The second test release. It fixes the first problem a tester found, adds a way to delete your account, and moves the desktop app
to a current, supported version of Electron.

## Download

- **Windows:** `CinemaTrack Setup 0.2.0.exe`
- **Android:** `CinemaTrack-0.2.0.apk`

Both are not code-signed yet, so Windows shows a "protected your PC" warning (More info → Run anyway) and Android asks you to allow
installing from this source. Step-by-step help is in the [tester guide](../tester-guide.md).

**Updating:** install over the old version; your account and lists stay. On the desktop, sign in again if the app asks.

## What's new

- **Fixed: lists carried over between accounts on one computer.** If you signed out of one account and into another on the same
  desktop, the second account received the first one's watchlist and statistics. Now every account gets only its own lists (the
  previous account's local file is kept aside as a backup, and its lists come back from the cloud when it signs in again).
  Thank you to the tester who found this.
- **Delete your account.** Desktop: Settings → *Delete account…*. Android: Statistics → the sign-out button → *Delete account*.
  After asking for your password again it deletes the account and everything stored online: lists, ratings, notes and Watch Together sessions.
- **A current Electron on the desktop** (44 instead of 31, which is no longer supported). The installer is also free of native
  components, and there are no known vulnerabilities in what ships.
- Under the hood: tests for the desktop database layer, and the API now tells apps how many AI calls a person has left today.

## Good to know

- You need an account with a **real email address**. Your lists and notes are private to you.
- The AI features have daily limits (for example 30 chat messages and 10 Watch Together picks per person).
- The Instagram lookup is best effort: it works best when the caption names the movie.
- The Android build includes an update of the AppCompat library: if the language button (EN/TR) ever misbehaves, please say so.
